# Examine as Configurações do GitHub Copilot e os Recursos da Interface do Usuário

## 📋 Sobre este Repositório

Este repositório contém materiais educacionais para explorar e aprender sobre as configurações e recursos da interface do usuário do GitHub Copilot no Visual Studio Code.

O GitHub Copilot é um assistente de programação baseado em IA que oferece uma experiência fluida e personalizável para desenvolvedores. Através deste material, você aprenderá a configurar e utilizar efetivamente o Copilot em seu fluxo de trabalho.

## 🎯 Objetivos de Aprendizado

Ao completar este exercício, você será capaz de:

- ✅ Acessar e configurar as opções do GitHub Copilot no VS Code
- ✅ Personalizar o Copilot para diferentes linguagens de programação
- ✅ Utilizar efetivamente a interface do usuário do Copilot
- ✅ Navegar entre sugestões inline de código
- ✅ Usar o GitHub Copilot Chat para assistência em programação
- ✅ Aplicar atalhos de teclado para aumentar a produtividade
- ✅ Configurar o Copilot por projeto/workspace

## 🔧 Configuração Inicial

1. **Instale o Visual Studio Code**
   - Download: https://code.visualstudio.com/

2. **Instale a extensão GitHub Copilot**
   - Abra o VS Code
   - Vá para a aba de Extensões (`Ctrl+Shift+X`)
   - Procure por "GitHub Copilot"
   - Clique em "Install"

3. **Autentique com sua conta GitHub**
   - Após instalar, clique no ícone do Copilot na barra de status
   - Siga as instruções para fazer login

4. **Verifique se está funcionando**
   - Crie um novo arquivo `.js` ou `.py`
   - Comece a escrever código
   - Observe se aparecem sugestões em cinza
